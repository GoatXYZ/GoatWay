# GoatWay 1.0.0

For WoW Forever beta (Interface 16001).

- In-world waypoint and pinpoint markers in the GoatQuest look.
- Arrow or ground halo navigation.
- Optional following of GoatQuest's guide arrow and accent colour.
- `/gw` settings and `/way` waypoint commands.

Download `GoatWay-1.0.0.zip` and extract it into `Interface/AddOns`. The archive
contains the `GoatWay` folder. Fully restart the game after installation.
